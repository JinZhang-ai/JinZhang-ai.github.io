## Overview

**FinMemRec** explores dynamic collaborative memory for financial product and asset recommendation.

The framework maintains provisional interaction episodes, consolidates mature preference evidence over time, and retrieves relevant personal and collaborative memories to support listwise recommendation with a frozen language model.

The central question is how delayed memory consolidation and context-aware retrieval can help recommendation agents adapt to evolving user preferences.
